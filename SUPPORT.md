# Support

Sovereign Code Runtime is currently a source preview, not an announced supported binary release.

Use GitHub Issues for reproducible source defects and focused feature requests. Include the exact commit SHA and environment information requested by the issue form.

Do not use public Issues for vulnerabilities, credentials, private workspace data, or exploit details. Use GitHub Private Vulnerability Reporting for suspected security issues.

There is currently no guaranteed response time, compatibility SLA, or long-term-support branch. Documentation and CI describe the current public main branch unless stated otherwise.
