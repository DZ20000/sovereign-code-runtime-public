# Community conduct

Keep technical discussion respectful, evidence-based, and focused on the work. Do not harass, threaten, discriminate, impersonate another contributor, or publish another person's private information. Disagreement about code is not permission for personal attacks.

Maintainers may moderate project-controlled discussions and contributions, explain the relevant behavior, and ask participants to correct it. Apply moderation consistently and proportionately. This source snapshot does not establish a dedicated enforcement team, private reporting inbox, appeal service, or guaranteed response time.

Raise non-sensitive conduct concerns with an independently verified maintainer contact. Do not expose private information in a public report. When a private channel has not yet been configured, request one without including sensitive details. Security issues follow [SECURITY.md](SECURITY.md).
